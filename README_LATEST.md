# مدرسك — نسخة v7.0 تعدد الفصول

## الجديد
- المدرس يقدر يختار أكثر من فصل في نفس الإعلان.
- ممنوع خلط الابتدائي مع الإعدادي أو الثانوي داخل نفس الإعلان.
- حذف اختيارات "مرحلة كاملة" من الصفوف.
- حذف البحث اليدوي من الصفحة الرئيسية والاعتماد على الفلاتر فقط.
- فلترة الصف تعتمد على `grades` وليس `grade` فقط.

## Supabase
تمت إضافة:
- `ads.grades` من نوع jsonb
- `ads.grade_section` من نوع text
- فهارس لتحسين الفلترة

لو كنت شغلت التعديل بالفعل من الشات، لا تحتاج تشغيل SQL مرة ثانية.

# مدرسك — آخر نسخة كاملة للموقع

هذه الحزمة تحتوي على ملفات المشروع كاملة مع آخر الإصلاحات التي اتعملت:

## الإصلاحات الموجودة في هذه النسخة

### 1) الأمان
- منع فهرسة صفحات الإدارة والدخول ولوحة المدرس.
- استخدام Supabase Auth للإدارة بدل بيانات Admin داخل الواجهة.
- ربط حساب الإدارة بجدول profiles في Supabase.
- تفعيل RLS للإدارة والزائر.

### 2) رسائل مرحلة الانطلاق
- زر "إظهار رسالة أن المنصة في مرحلة الانطلاق" أصبح يطبق على كل الصفحات.
- عند إغلاقه تختفي رسائل/أقسام مرحلة الانطلاق من الصفحة الرئيسية وصفحة الانضمام وباقي الصفحات.
- تم رفع نسخة الكاش إلى v=6.5 حتى تظهر التغييرات بعد الرفع.

### 3) التصميم
- إصلاح كلاس btn-white و btn-outline-white في style.css ليظهر زر "عرض ملفي" بشكل صحيح في لوحة المدرس.

### 4) تحسين عرض النصوص
- إضافة escapeAttr في config.js.
- تحسين بعض أماكن عرض النصوص لتقليل مشاكل النصوص الغريبة أو HTML غير آمن.

## طريقة الرفع على GitHub

1. فك الضغط عن الملف.
2. افتح Repository الخاص بالموقع.
3. ارفع كل الملفات الموجودة داخل الحزمة مكان الملفات القديمة.
4. وافق على Replace للملفات القديمة.
5. انتظر GitHub Pages دقيقة أو دقيقتين.
6. افتح الموقع واعمل Ctrl + F5.

## اختبار سريع

### اختبار الصفحة الرئيسية
- افتح index.html
- تأكد أن الإعلانات تظهر.
- تأكد أن رسالة مرحلة الانطلاق تظهر أو تختفي حسب إعداد لوحة الإدارة.

### اختبار صفحة الانضمام
- افتح join.html
- لو زر مرحلة الانطلاق مقفول، المفروض لا تظهر عبارات "مرحلة الانطلاق" أو "المدرسين الأوائل".

### اختبار الإدارة
- افتح login.html?role=admin
- سجل دخول بإيميل الإدارة الموجود في Supabase Auth.
- افتح لوحة الإدارة وجرب الإعدادات.

## ملاحظة مهمة
ملفات SQL مثل supabase_setup.sql و fix_rls.sql موجودة للتوثيق/الإعداد، لا تشغلها مرة ثانية إلا لو أنت فاهم محتواها أو محتاج تعيد بناء قاعدة البيانات.
